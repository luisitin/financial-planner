How this board works
  1. Press Copy prompt and paste it into ChatGPT, Gemini, Muse, another Claude or any tool.
  2. Tap the tools you sent it to under Sent to.
  3. When the answer comes back, paste it or attach the file under Answer and notes, then save.
  4. Tick Done when you are finished with that prompt.

Claude copies every saved answer to the PC (into ai-responses/<prompt id>/), tries the good changes on a branch, runs the tests and reports back.
